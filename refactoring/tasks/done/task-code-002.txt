# Frontend API client and theme cleanup

Роль: developer-frontend
Статус: DONE

Выполнено в рамках scope:
- frontend/src/api.ts: централизована обработка ошибок API; добавлены безопасные сообщения для 401, JSON/non-JSON и пустых ответов; 204 возвращается без JSON parse; сохранены URL composition, методы, пути, payloads, x-access-token и VITE_TOKEN.
- frontend/src/main.tsx и frontend/src/App.tsx: theme state поднят в Root как единый источник; сохранены initial state из localStorage, toggle, запись localStorage и CSS data-theme; ConfigProvider теперь синхронно меняет algorithm.

Не изменялись: backend auth/CORS, token header/value handling, API paths/payloads, nginx, DB и продуктовая палитра.

Проверки:
- frontend TypeScript typecheck (`pnpm exec tsc --noEmit`) — успешно.
- frontend production build (`pnpm build`) — успешно.
- Известное предупреждение о размере JS chunk (~1.03 MB minified) сохранилось, новой регрессии не выявлено.

Тестовый harness не добавлялся: в репозитории отсутствует frontend test runner; расширение инфраструктуры не входило в scope.
